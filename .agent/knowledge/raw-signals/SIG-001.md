# SIG-001: Relative Import Failing in Modular Build

## Encountered Issue
When attempting to compile `hero.tsx`, a `Module not found` error was thrown because the path `../../components/marketing/terminal-demo` resolved incorrectly during Turbopack's dynamic module resolution.

## Applied Fix
Refactored the relative import to use the TypeScript path alias:
`- import { TerminalDemo } from "../../components/marketing/terminal-demo";`
`+ import { TerminalDemo } from "@/components/marketing/terminal-demo";`

## Significance
This indicates a systemic fragility with relative routing in the monorepo workspace.
