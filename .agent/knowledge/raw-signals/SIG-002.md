# SIG-002: CDP Auto-Accepts Destructive Undo Dialogs

## Signal
Chrome DevTools Protocol (CDP) auto-click handler was accepting "Confirm Undo" dialogs in Antigravity, causing unintended data loss when users pressed Back/Undo.

## Context
`cdpHandler.ts` in `pikakit-extension` injects auto-accept scripts for agent workflow dialogs. The guard only checked for `'undo action'` string literally, missing variations like "Confirm Undo", "Revert changes", "Discard edits".

## Resolution
Extended the guard to check for keywords: `undo`, `revert`, `discard` (case-insensitive) in the dialog text content. Returns `false` (block auto-click) for any dialog containing destructive keywords.

## Lesson
When building auto-accept logic for UI dialogs, always guard against destructive operations using broad keyword matching rather than exact string matching. Dialog text varies across applications and updates.
