# SIG-005: memory.sqlite Is Runtime Cache, Not Knowledge Store

## Signal
Confirmed that `.agent/memory.sqlite` (49KB) is a WASM embedding vector cache used by the PikaKit Engine VS Code extension for semantic pattern matching. It is NOT part of the knowledge wiki pipeline.

## Context
The knowledge wiki is entirely Markdown-based (`knowledge/` directory). The `memory.sqlite` serves a different purpose — caching embeddings for the Local WASM Embedding Engine (@xenova/transformers) that powers fast, offline semantic search in the extension.

## Resolution
No change needed. Architecture is correct:
- `knowledge/` = Markdown wiki (LLM-maintained, human-readable)
- `memory.sqlite` = Binary embedding cache (runtime optimization, machine-only)

Both live under `.agent/` which is the correct parent for both concerns.

## Lesson
Separate knowledge storage (human-readable markdown for LLM context) from runtime caches (binary databases for machine optimization). They serve different consumers and have different lifecycle requirements.
