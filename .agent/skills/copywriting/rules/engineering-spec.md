# Conversion Copywriting Quality Gate

## Preconditions

- Identify the target persona, reading context, user intent, and desired business action.
- Define reading grade level, brand voice attributes, and accessibility constraints.
- Verify competitive claims, factual statements, and legal disclaimers.

## Procedure

1. Formulate a single clear value proposition headline that directly addresses user motivation.
2. Structure copy hierarchically with scannable headers, bullet points, and concise paragraphs.
3. Align call-to-action language with user expectations; eliminate ambiguous or dark patterns.
4. Verify accessibility: ensure sufficient contrast, descriptive link text, and alternative text.
5. Review draft copy for clarity, conciseness, tone consistency, and factual integrity.

## Rollback

Revert to the previously validated copy baseline if readability, conversion clarity, or user accessibility metrics degrade.

## Exit Gate

Pass when copy satisfies accessibility requirements, includes unambiguous calls to action, adheres to brand voice, and eliminates unverified claims.
